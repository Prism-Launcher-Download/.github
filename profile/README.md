## Overview

🎮 Prism Launcher is an open-source Minecraft launcher designed around separate game instances. Each instance can have its own Minecraft version, mods, resource packs, shader packs, settings, and configuration.

✨ This approach makes Prism Launcher particularly useful for players who regularly switch between different Minecraft versions or maintain several modded setups.

📂 Instead of keeping everything inside one general configuration, each instance can remain independent, making it easier to organize modded Minecraft, vanilla Minecraft, testing environments, and different modpacks.

## Prism Launcher

🎮 Prism Launcher provides a clean interface for managing Minecraft installations without combining every setup into one configuration.

📂 Each instance can have its own collection of mods, resource packs, shaders, worlds, settings, and Minecraft version.

⚙️ This makes the launcher convenient for players who want separate environments for different modpacks or Minecraft versions.

## Minecraft Instance Management

🧩 Instances are one of the main concepts behind Prism Launcher. A new instance can be created with a selected Minecraft version and compatible mod loader.

🔄 Once several instances are available, you can switch between them without rebuilding the configuration each time.

🗂️ Separate instances can be useful for survival worlds, creative projects, technical testing, modded gameplay, or different Minecraft releases.

## Minecraft Mod Manager

🔧 Prism Launcher includes tools for managing Minecraft mods within individual instances.

📚 Supported mod sources include Modrinth and CurseForge, allowing compatible projects to be discovered and added through the launcher.

✨ Mods can remain associated with the instance where they are used, helping keep different Minecraft configurations separated.

## Minecraft Modpacks

📦 Prism Launcher supports installing modpacks from several popular sources, including Modrinth, CurseForge, FTB, Technic, and other supported providers.

🎮 Modpacks can be installed as individual instances, giving each collection its own Minecraft version, mods, settings, and related files.

🔄 This makes it easier to switch between different modpack environments without mixing their configurations.

## Fabric Minecraft

🎮 Open Prism Launcher and sign in with a supported Minecraft account.

📂 Select **Add Instance** and choose the Minecraft version, mod loader, or modpack you want to use.
